🔗 OneDrive koppelen — geen Azure nodig

Koppel de tool aan een Excel-bestand op OneDrive via een deellink. Geen IT, geen Azure, geen wachtwoorden — alleen een OneDrive-link plakken.

1
Maak een Excel-bestand aan op OneDrive
Ga naar onedrive.com → klik + Nieuw → Excel-werkmap.
Noem het bestand bijv. hs_codes.xlsx.
Hernoem het eerste tabblad naar HS Codes (dubbelklik op de tabnaam onderaan).
Laat het bestand leeg — de tool vult het zelf in.
📁 Tip: Zet het bestand in een gedeelde Teams-map zodat logistiek er altijd bij kan, ook als jij afwezig bent.
2
Maak een deellink aan — "Kan bewerken"
Open het Excel-bestand op OneDrive.
Klik rechtsboven op Delen (of het deelicoon).
Kies: Iedereen met de link kan bewerken.
Klik Koppeling kopiëren.
⚠️ Let op: Kies "Kan bewerken", niet "Kan weergeven" — anders kan de tool geen wijzigingen opslaan.

🔒 Over beveiliging: De link werkt alleen voor dit specifieke Excel-bestand. HS-codes zijn geen gevoelige bedrijfsdata, maar deel de link niet buiten het team.
3
Plak de deellink hieronder
4
Jouw naam (voor wijzigingshistorie)
Wordt opgeslagen bij elke wijziging — zodat je kunt zien wie wat heeft aangepast.
5
Jouw rol
Logistiek kan bewerken en opslaan naar OneDrive. Sales/management kan alleen raadplegen.

📋 Hoe collega's de tool instellen

Stuur collega's dit bericht:

Hoi! Hier is de HS Code Tool: [link naar HTML-bestand]
1. Open de tool en klik op ⚙ Instellingen
2. Plak deze deellink in het veld: [jouw OneDrive deellink]
3. Vul je naam in en kies rol "Sales / Management"
4. Klik Instellingen opslaan — de tool laadt automatisch de actuele data.

⚡ Automatische synchronisatie
De tool synchroniseert automatisch elke 5 minuten. De gekleurde stip bovenin toont de status:
🟢 Groen = verbonden en actueel  |  🟡 Geel = niet verbonden  |  🔴 Rood = fout

Klik op de stip of de knop ↻ Vernieuwen voor een handmatige sync.
