🐙 GitHub synchronisatie instellen

De data wordt opgeslagen als JSON-bestand in je GitHub-repository. Geen Azure, geen SharePoint-rechten, geen IT nodig. Logistiek schrijft via een persoonlijk token — sales leest zonder token.

1
Maak een GitHub Personal Access Token aan
Ga naar github.com → klik rechtsboven op je profielfoto → Settings
Scroll helemaal naar beneden → Developer settings
Klik Personal access tokens → Tokens (classic) → Generate new token (classic)

Vul in:
· Note: HS Tool
· Expiration: No expiration
· Vink aan: repo (het bovenste vakje — dan zijn alle sub-opties automatisch aangevinkt)

Klik Generate token → kopieer de token (begint met ghp_) — je ziet hem maar één keer!
🔒 Het token geeft alleen toegang tot jouw eigen repositories. Deel het niet — bewaar het als een wachtwoord.
